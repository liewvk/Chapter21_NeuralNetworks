# Chapter 21: Neural Networks

This repository contains implementations and examples related to neural networks, covering fundamental concepts and practical applications in deep learning.

## Overview

This project explores neural network architectures, training methodologies, and various machine learning techniques using Python. It serves as a comprehensive resource for understanding how neural networks work and how to implement them from scratch or using popular frameworks.

## Contents

- **Core Neural Network Implementations**: Fundamental building blocks including layers, activation functions, and optimization algorithms
- **Training Procedures**: Methods for training neural networks with backpropagation and gradient descent
- **Example Applications**: Practical examples demonstrating neural networks on real-world problems
- **Utilities**: Helper functions for data processing, visualization, and evaluation

## Requirements

- Python 3.7+
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow/Keras (optional, for advanced examples)

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/liewvk/Chapter21_NeuralNetworks.git
cd Chapter21_NeuralNetworks
pip install -r requirements.txt
```

## Usage

Each module can be run independently. Refer to individual scripts for specific usage instructions.

Example:
```python
python script_name.py
```

## Key Topics Covered

- Perceptrons and Multi-layer Perceptrons (MLPs)
- Activation Functions (ReLU, Sigmoid, Tanh)
- Loss Functions and Optimization
- Forward and Backward Propagation
- Hyperparameter Tuning
- Model Evaluation and Validation
